E-commerce Sales Performance Dashboard

Overview

An interactive Tableau dashboard designed to analyse e-commerce sales, profitability, customer behaviour, and promotional performance. The dashboard provides a consolidated view of key business metrics and enables exploration across stores, brands, customer segments, and membership groups.

Interactive Dashboard

Explore the dashboard using the interactive filters to examine sales performance across different periods, customer segments, membership types, and brands.

Open Dashboard in Tableau Public →

Dashboard Highlights

The dashboard presents net sales, gross margin, transaction volume, and return rate alongside monthly sales trends, store-level comparisons, brand performance, customer segment analysis, and promotional performance by membership status.

Tableau · Interactive Dashboards · KPI Reporting · Business Performance Analysis · Data Visualisation

Key Takeaway

This project demonstrates how interactive dashboards can bring together multiple business performance indicators to support clearer reporting and exploratory analysis.
